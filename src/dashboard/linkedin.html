🔗 LinkedIn Outreach

Captured recruiters/HR — AI connection note ke saath. Review karo, copy karo, profile kholo, khud connect bhejo.
Kaise use karein: LinkedIn pe kisi recruiter/HR ka profile kholo → extension me "Capture recruiter" dabao → wo yahan aa jayega note ke saath. Phir Open profile → Connect → Add a note → yahan se note Copy karke paste karo → Send.
Note: extension khud kisi ko message/connect nahi bhejta — sending hamesha tum karti ho (LinkedIn rules).
